# Hitesh Warhate — Portfolio

A Netflix-style portfolio: cinematic intro, "Originals" project posters, skill universe, journey episodes, and a playable Bug Runner game in the footer.

Built with React, Vite and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Edit content

All text, projects, skills and links live in [`src/data.js`](src/data.js).
