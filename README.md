## 🚀 Overview

A modern, highly interactive, and visually engaging portfolio website built to showcase my projects, skills, and experience as a Software Developer. The design emphasizes a dark-themed, tech-focused aesthetic with custom animations and dynamic background effects.

## ✨ Features

- **Next.js & React:** Built with the latest Next.js App Router for optimal performance and SEO.
- **Tailwind CSS & Framer Motion:** Beautifully styled with complex, smooth animations.
- **Immersive Visuals:** Includes unique visual effects like a Grid Background, Noise Overlay, Custom Cursor, and Floating Code Snippets.
- **Fully Responsive:** Perfectly adapts to mobile, tablet, and desktop screens.
- **Dark Mode First:** A polished, modern dark-mode design layout.

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have Node.js and npm (or yarn/pnpm) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   cd Hitesh-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   # or
   yarn install
   # or
   pnpm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   # or
   yarn dev
   # or
   pnpm dev
   ```

4. **Open in browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to see the application in action.
